# Карта аудита folder-scan

Автоматические проверки относятся к поведению программы. Объяснение решения
студентом и оценка его понимания остаются отдельной устной частью аудита.

## Обязательные пункты

| Требование | Подтверждение |
| --- | --- |
| Go, `go.mod`, `main.go`, отдельный ageprofile | Структура репозитория, `make all test` |
| Только разрешённые импорты; без запуска системных команд из Go | `scripts/check_imports.py`, отдельная стадия CI |
| Нет аргументов; аргумент-файл; аргумент-каталог | Точные сравнения в `scripts/audit.py` |
| `-l`, в том числе `/usr/bin`, ссылки и колонки | Сравнение stdout байт в байт с нативным `ls` |
| `-a`, `-r`, `-t`, объединённые и раздельные флаги | Сравнения всех 32 сочетаний `l a r t R`, отдельные тесты парсера |
| `-la /dev`, включая специальные файлы | Сравнение стабильных записей между двумя независимыми снимками `ls`; ACL-маркер игнорируется по ТЗ |
| Каталог с именем `-` | Fixtures и сравнение с `ls -` |
| Ссылки на файл/каталог с завершающим `/` и без него | `TestLinkOperandsAndTrailingSlash` + собранный бинарник |
| Профиль после каталога, без нулевых категорий | `TestDirectoryProfilesAndEmptyCases`, Python-проверка всех категорий |
| Нет профиля для файла и пустого каталога | Unit- и сквозные тесты, в том числе пустой каталог с `-a` |
| Отдельный helper для одного времени и функция для среза | `Label`, `Classify`, фиксируемые `LabelAt`, `ClassifyAt` |
| Границы 7, 31, 366 полных суток | `TestWholeDayBoundaries`: ровно граница и наносекунда перед ней |
| `go test ./...` проходит | Локальный запуск и GitHub Actions |

## Все бонусы

| Бонус | Подтверждение |
| --- | --- |
| `-R` | Итеративный обход, сравнение с нативным `ls` |
| Цвета | `--color=always/auto/never`, проверка ANSI и отсутствия ANSI для pipe в auto |
| Дополнительные флаги | `-A -S -d -n -i -F -p -1 -k -L -H -P -G` и длинные параметры |
| `-lRr`, `-alRrt` | Прямые сравнения вложенного дерева |
| Профиль каждого подкаталога | Подсчёт профилей и проверка локальности статистики |
| `-R ~` меньше 1,5 с | На машине разработки три запуска: 0,9807 / 0,7229 / 0,8510 с, статус 0 |

## Дополнительные испытания

- Сортировка 10 000 перемешанных имён; прямой и обратный порядок, равные mtime.
- Жёсткие ссылки, бит setuid без execute, FIFO и Unix-сокет, скрытые имена,
  пробелы, кавычки, табуляция, перевод строки и кириллица в именах.
- Оборванная ссылка, недоступный каталог и неверный путь рядом с корректным.
- Циклические ссылки при `-L`, а также два независимых пути к одному каталогу.
- Дерево глубиной 256 с лимитом **32 файловых дескриптора**.
- Параллельное создание и удаление файлов во время 20 запусков `-lR`.
- Защита от подмены каталога FIFO и от разыменования подменённой ссылки при
  физическом обходе; проверка inode фактически открытого каталога.
- Ошибки записи, короткие записи и нулевая успешная запись в stdout.
- Будущие и очень старые даты, високосная дата и независимость возраста от зоны.
- Нативная граница переключения даты на год: BSD и GNU проверяются отдельно.
- `go vet`, детектор гонок, фаззинг возраста и опций. Первый локальный цикл
  фаззинга обработал более **4,7 млн входов** без нарушения проверяемых свойств.

## Как сравниваются изменяемые системные каталоги

Для обычных fixtures и `/usr/bin` требуется полное совпадение stdout после
отключения дополнительного профиля. Тест не обрезает колонки и не нормализует
пробелы, владельцев, размеры, даты или порядок.

В macOS некоторые устройства в `/dev` меняют номер при каждом `lstat`, поэтому
два последовательных запуска самого `ls` отличаются. Аудит получает системный
снимок до запуска программы и ещё один после. Байт в байт сравниваются записи,
не изменившиеся между этими независимыми снимками; список исключений не зашит
по именам устройств. На локальной машине совпала **341 стабильная запись**,
ещё 4 изменились между системными снимками. ACL-маркер исключается согласно ТЗ.

Это не атомарный снимок файловой системы: временные изменения не выдаются за
ошибку форматирования или за доказательство совпадения нестабильных данных.

## Воспроизведение и границы

```sh
make imports fmt-check vet test race audit stress
GOMAXPROCS=4 make fuzz
python3 scripts/stress.py --home
```

Сквозной аудит использует `LC_ALL=C`, `TZ=UTC`, стандартные единицы блоков и
отключённые сторонние настройки цветов/формата. Подробный список ограничений
локали, ACL-маркера macOS и нестандартных переменных окружения есть в README.

Скорость зависит от диска, нагрузки, количества записей и прав доступа.
Воспроизводимое дерево CI содержит 10 000 файлов; замер реального домашнего
каталога запускается явно, выводит только время, статус и число диагностик,
не публикует имена личных файлов.

## Источники формата

- [Руководство GNU ls](https://www.gnu.org/software/coreutils/manual/html_node/ls-invocation.html).
- [Формат дат GNU ls](https://www.gnu.org/software/coreutils/manual/html_node/Formatting-file-timestamps.html).
- Локальная страница `man ls` в macOS и [реализация вывода Apple](https://github.com/apple-oss-distributions/file_cmds/blob/main/ls/print.c)
  для уточнения наблюдаемой 182-дневной границы и округления до секунд.

Исходники проекта написаны отдельно; системная команда служит внешним эталоном
в тестовом скрипте и не является частью реализации Go.
